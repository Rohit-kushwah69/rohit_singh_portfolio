# 🚀 Rohit Singh — Personal Portfolio

- A modern, responsive and interactive personal portfolio website built to showcase my skills, projects, experience and professional journey.

- The portfolio includes a React frontend and a Python Flask backend for handling the contact form and sending messages directly to my email.

---

## 🌐 Live Portfolio

🔗 **[Visit My Portfolio](https://rohit-singh-portfolio-six.vercel.app/)**

---

## 📸 Features

- ✨ Modern and premium UI
- 📱 Fully responsive design
- 🎨 Dark themed portfolio
- ⚡ Smooth animations and transitions
- 🧑‍💻 About Me section
- 🛠️ Skills & Technologies section
- 🚀 Projects showcase
- 📩 Working contact form
- 📧 Email notifications using Resend
- 🔗 Social media links
- 📄 Resume / professional information
- 🌐 React Router navigation
- 🚀 Deployed on Vercel
- 🐍 Flask backend deployed on Render

---

## 🛠️ Tech Stack

### Frontend

- React Router
- React Icons
- Vite

### Backend

- Python
- Flask

- Resend API

- Vercel — Frontend

- GitHub — Source Code
